# keyboard.wtf 1.4.22 for Windows

- Handles spoken follow-ups and positional Chrome tab requests more reliably.
- Translates longer selections with progress and copies the complete result to the clipboard.
- Shows progress during longer tasks and better matches app names when closing windows.

Use the regular Windows x64 installer for an in-place upgrade that preserves settings. This installer is unsigned, so Windows may show an unknown-publisher warning. Updates use the normal installer.

Public connectors will become available after production authorization. Chrome Helper is installed separately through the Chrome Web Store.
